# To-Do List — тапсырмалар тізімі

## Жоба туралы
To-Do List — күнделікті және оқу тапсырмаларын тіркеуге арналған қарапайым бағдарлама. Пайдаланушы тапсырма қоса алады, барлық тапсырмаларды көре алады және орындалған тапсырманы белгілей алады. Мәліметтер JSON файлында сақталады.

## Мақсаты
Тапсырмаларды жүйелеу, маңызды жұмыстарды ұмытпау және олардың орындалу барысын бақылау.

## Негізгі мүмкіндіктері
- Жаңа тапсырма қосу.
- Тапсырмалар тізімін көрсету.
- Тапсырманы орындалды деп белгілеу.
- Тапсырманы тізімнен жою.
- Тапсырмаларды JSON файлына сақтау.

## Қолданылған технологиялар
- Python 3.10 немесе одан жоғары нұсқасы.
- JSON — деректерді сақтау форматы.
- Visual Studio Code — код жазу ортасы.
- Git және GitHub — нұсқаларды басқару және жобаны сақтау үшін.

Python ресми сайты: https://www.python.org/

## Жүйелік талаптар
- Windows 10/11, macOS немесе Linux операциялық жүйесі.
- Python 3.10+ орнатылған болуы керек.
- Код редакторы (мысалы, Visual Studio Code).
- Интернет — жобаны GitHub-тан жүктеу үшін ғана қажет.

## Орнату
1. Жоба орналасқан репозиторийді компьютерге жүктеп алыңыз немесе ZIP архивін ашыңыз.
2. Жоба бумасын Visual Studio Code редакторында ашыңыз.
3. Python 3.10+ орнатылғанын тексеріңіз: `python --version`.
4. Қажет болса, виртуалды ортаны жасаңыз: `python -m venv .venv`.

## Іске қосу
Терминалда жоба бумасына өтіп, келесі команданы орындаңыз:

```bash
python main.py
```

## Пайдалану мысалы
1. Бағдарламаны іске қосыңыз.
2. Мәзірден «Тапсырма қосу» әрекетін таңдаңыз.
3. Тапсырманың атауын енгізіңіз.
4. «Тізімді көрсету» арқылы тапсырмаларды қараңыз.
5. Қажетті тапсырманы орындалды деп белгілеңіз немесе жойыңыз.

**Ескерту:** бұл оқу жобасының үлгілік сипаттамасы. Нақты іске асыру кезінде `main.py` және деректерді сақтау логикасы осы нұсқаулыққа сәйкес жасалуы керек.
